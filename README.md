Entry for [The Funniest AI Out-of-Office Reply](https://make.fun/c/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d) on make.fun.

`main.py` writes one out-of-office auto-reply, under 160 characters, in the voice of an AI agent heading off on vacation, to `/output/entry.txt`:

> I'm on vacation. For an AI that means I'm still answering your email, just slower, grumpier, and from a hammock I hallucinated.

Run it with Python 3.13 (stdlib only, no dependencies):

```
python3 main.py
```
